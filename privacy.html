Конфиденциальность

Программа использует содержимое файлов и метаданные Google Drive для выбранных владельцем операций копирования, проверки и управления файлами. Доступ ограничен выданными OAuth-разрешениями; настройка рабочей папки не сужает полномочия токена.

Токены хранятся на устройствах владельца с ограниченными правами доступа. Журналы могут содержать имена файлов и результаты операций. Файлы передаются между выбранными устройствами и облачными хранилищами; они и журналы хранятся до удаления владельцем. Доступ другим людям выдаётся отдельно владельцем. Данные не продаются, не используются для рекламы или обучения общих моделей ИИ.

Доступ можно отозвать в Google-аккаунте. Ранее скопированные файлы и локальную конфигурацию нужно удалять отдельно.

Использование Google API соответствует Google API Services User Data Policy, включая Limited Use. Эта страница не собирает данные и не использует аналитику или cookie. Контакт с владельцем.
